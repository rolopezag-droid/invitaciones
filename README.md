# Invitación de graduación de Adela

Aplicación web de temática arquitectónica para compartir la invitación de graduación de Adela Sánchez Dueñas, registrar confirmaciones de asistencia y consultar la lista de invitados.

## Estructura

- `Frontend/`: aplicación web, rutas del servidor y persistencia D1.
- `Backend/`: reservado para integraciones independientes que puedan necesitarse más adelante, como Apple Wallet.

## Estado

La primera versión visual está en construcción. Los datos definitivos del evento se incorporarán antes de publicar la invitación.
